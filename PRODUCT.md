# Product

## Register

product

## Users

The primary user is an alliance manager for Legion of Valkyrie who checks screenshots, reviews OCR results, compares member power, and tracks weekly Boss damage. They use the page on a desktop monitor while collecting daily game screenshots, with occasional mobile checks for quick review.

## Product Purpose

This dashboard turns alliance and Boss screenshots into a trusted operational report. It needs to show the newest alliance status, weekly Boss ranking, daily Boss damage delta, member roster changes, and OCR review work without forcing the user to inspect raw JSON or folders.

## Brand Personality

Focused, composed, and decisive. The interface should feel like a clear command room for weekly alliance operations, not a marketing page or decorative game fan page.

## Anti-references

Avoid bloated card grids, blurry glass panels, neon-heavy game UI, unreadable low-contrast tables, oversized hero sections, and decorative effects that reduce data density. Avoid any design that hides the tenth rank, wastes vertical space under Boss and Members, or makes upload and review states ambiguous.

## Design Principles

1. Lead with the latest truth: the first screen must expose the newest report metrics, Boss weekly ranking, and battle Top 10 without extra navigation.
2. Make review work obvious: OCR uncertainty, corrections, locked archives, and upload status must be visible and actionable.
3. Preserve operational density: show enough rows and rankings for decision-making while keeping text legible.
4. Keep controls near their data: week and snapshot filters belong with Boss data, search and sorting belong with member data.
5. Respect existing records: visual polish must not break upload, archive, sorting, filtering, or correction workflows.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, readable Chinese/Japanese/special-character names, tabular number alignment, reduced-motion support, and responsive layouts that avoid horizontal page overflow.
